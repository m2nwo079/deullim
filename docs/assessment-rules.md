# 자세 평가 규칙 (v1, algorithm_version: reba-2d-v1)

## 성격
- 들림의 평가는 상시 선별과 정밀 조사 대상 추천을 위한 것이며, 법정 유해요인조사를 대체하지 않는다.
- 평가 방법은 REBA를 따르되, 2D 영상으로 판정할 수 없는 항목은 아래 규칙대로 처리한다.
- 판정하지 않는 항목이 있으므로 들림의 점수는 실제 REBA 점수보다 낮게 나올 수 있다. 화면과 보고서 초안에 이 점을 표시한다.

## 근거 자료
- REBA 원 논문: Hignett & McAtamney (2000), Applied Ergonomics (서지 정보는 구현 전에 원문으로 재확인)
- KOSHA GUIDE H-9 근골격계부담작업 유해요인조사 지침
- 부위별 점수 구간, 표 A·B·C, 조치 수준은 구현 시 원 논문 표와 한 칸씩 대조해 코드화한다. 이 문서에 표 값을 옮겨 적지 않는다.

## 입력
| 입력 | 출처 |
|---|---|
| 관절 좌표 시계열 | 브라우저 MediaPipe Pose Landmarker (분석 횟수 초당 최대 15회) |
| 영상 가로·세로 크기(픽셀) | 촬영 화면. MediaPipe 좌표는 가로·세로를 각각 0~1로 나눈 값이므로, 크기를 곱해 실제 비율로 되돌린 뒤 각도를 잰다 |
| 하중·힘 (5kg 미만, 5~10kg, 10kg 초과, 충격 여부) | 관리자가 단위작업마다 입력 |
| 손잡이 상태 (좋음, 보통, 나쁨, 허용 불가) | 관리자가 단위작업마다 입력 |
| 1분 이상 정적 유지 여부, 불안정한 자세 여부 | 관리자가 단위작업마다 입력 |
| 앉은 작업 여부, 팔 지지 여부 | 관리자가 단위작업마다 입력 |
| 하루 작업 시간 | 관리자가 단위작업마다 입력 (최적화에서 사용) |

## 전처리
- 가시성(visibility)이 VISIBILITY_MIN(기본 0.5) 미만인 점은 무효로 처리한다.
- 좌표는 몸통 길이(어깨 중점과 골반 중점 사이 거리)로 정규화한 뒤 One Euro 필터를 적용한다. 기기 해상도와 촬영 거리에 관계없이 같은 매개변수를 쓰기 위해서다.
  - 몸통 길이는 세션 안 유효 프레임 값의 중앙값 하나를 쓴다. 2D 영상에서는 몸통을 숙이면 보이는 길이가 줄어, 프레임마다 나누면 좌표 단위가 흔들리기 때문이다.
  - One Euro 매개변수: min_cutoff 1.0, beta 0.01, d_cutoff 1.0 (스파이크 값, 시작값). 좌표 단위가 몸통 길이이므로 beta는 실기기 테스트에서 다시 조정한다.
  - 점이 무효가 되면 그 점의 필터 상태를 비우고, 다시 유효해지면 그 값부터 새로 시작한다.
  - 시각이 직전 프레임보다 같거나 이르면 직전 필터 값을 그대로 쓴다.
- MediaPipe 입력 영상은 좌우반전하지 않는다. 좌우는 작업자 본인 기준이다.
- 작업자가 향한 쪽은 발 방향으로 먼저 정한다. 발뒤꿈치(29, 30) → 발끝(31, 32) 벡터의 가로 방향을 쓰고,
  유효한 발이 양쪽이면 둘 다 같은 방향일 때만 그 방향으로 본다.
  - 발로 정할 수 없을 때(유효한 발 없음, 양발 방향이 다름, 발 벡터의 가로 성분이 몸통 길이의 FOOT_MIN_OFFSET(기본 0.05, 시작값) 미만)만
    코가 몸통선의 어느 쪽에 있는지로 정한다. 코 기준만 쓰면 깊이 숙이고 고개를 든 자세에서 코가 몸통선 위로 올라가 방향이 뒤집히기 때문이다.
    가로 성분 기준은 정면에 가까운 발 방향에서 방향이 프레임마다 뒤집히는 것을 막기 위해서다.
  - 코로 판단할 수 없음: 코가 무효이거나, 코와 몸통선 사이 거리가 몸통 길이의 FACING_MIN_OFFSET(기본 0.1, 시작값) 미만일 때.
    정면 촬영에서 코가 몸통선 가까이 있어 프레임마다 방향이 뒤집히는 것을 막기 위해서다.
  - 발과 코 모두로 판단할 수 없으면 해당 프레임의 굽힘·젖힘 구분이 필요한 항목(몸통, 목, 위팔)은 굽힘으로 본다.

## 부위별 각도 (MediaPipe 랜드마크 번호)
| 부위 | 각도 정의 | 사용 점 |
|---|---|---|
| 몸통 | 수직 위 방향과 골반 중점 → 어깨 중점 벡터 사이 각도. 향한 쪽 기준으로 굽힘(+)과 젖힘(-) 구분 | 11, 12, 23, 24, 0, 29~32 |
| 목 | 몸통 벡터와 어깨 중점 → 귀 중점 벡터 사이 각도. 향한 쪽 기준으로 굽힘(+)과 젖힘(-) 구분. 귀가 한쪽만 유효하면 그 귀를 쓴다 | 0, 7, 8, 11, 12, 23, 24 |
| 위팔 (좌, 우) | 몸통 아래 방향 벡터와 어깨 → 팔꿈치 벡터 사이 각도. 향한 쪽 기준으로 앞(+)과 뒤(-) 구분 | 11~14, 23, 24 |
| 아래팔 (좌, 우) | 180 - 어깨·팔꿈치·손목 내각 | 11~16 |
| 손목 (좌, 우) | 아래팔 벡터와 손목 → (검지, 새끼 중점) 벡터 사이 각도 | 13~20 |
| 무릎 (좌, 우) | 180 - 골반·무릎·발목 내각 | 23~28 |
| 한쪽 다리 지지 | 좌우 발목 높이 차 / 몸통 길이 > UNILATERAL_RATIO(기본 0.5, 시작값). 양쪽 발목이 모두 유효할 때만 판정하고, 아니면 양발 지지로 본다 | 11, 12, 23, 24, 27, 28 |

- 한쪽 다리 지지의 분모를 어깨 너비에서 몸통 길이로 바꿨다. 측면 촬영에서는 보이는 어깨 너비가 0에 가까워져 비율이 커지고, 한쪽 다리 지지로 잘못 판정되기 때문이다.

- AI Hub 라벨의 목 기준점은 정수리이고 MediaPipe에는 정수리가 없어 귀 중점을 쓴다. 검증 시 이 차이를 함께 보고한다.

## 점수 구간 적용
- 부위별 점수 구간의 경계값은 낮은 점수 쪽에 넣는다 (예: 몸통 20도는 2점, 20도 초과부터 3점).
  아래팔은 60~100도가 1점이므로 60도와 100도는 1점이다.
- 몸통: 원문은 0도일 때만 1점(바로 섬)이지만, 2D 측정 오차를 고려해 TRUNK_UPRIGHT_DEG(기본 5도, 시작값) 이하를 바로 선 자세로 본다.
  연속값 측정에서는 정확히 0도가 거의 나오지 않아, 원문대로면 몸통 점수가 사실상 항상 2점 이상이 된다.
- 목: 원문은 젖힘이면 2점이지만, 2D 측정 오차를 고려해 NECK_EXTENSION_TOLERANCE_DEG(기본 5도, 시작값) 이하 젖힘은 젖힘으로 보지 않는다.
- 팔 지지(-1)를 적용한 위팔 점수는 최소 1점이다 (표 B에 0점 행이 없음).
- 시작값으로 표시된 상수는 web/src/core/reba-config.ts에 모은다.

## 판정하지 않는 항목 (MVP)
| 항목 | 처리 | 이유 |
|---|---|---|
| 목·몸통의 비틀림, 옆 굽힘 | 보정 점수 0 | 2D 영상에서 신뢰도가 낮음 (결정됨) |
| 위팔 벌어짐·회전, 어깨 들림 | 보정 점수 0 | 같은 이유로 제외 (결정됨) |
| 손목 꺾임(편위)·비틀림 | 보정 점수 0 | 같은 이유로 제외 (결정됨) |
| 팔 지지 (-1) | 관리자 입력으로 반영 | 영상으로 판단하기 어려움 |
| 손목 각도 (검지·새끼 점이 무효인 프레임) | 손목 점수 1점, 위팔·아래팔은 그대로 계산 | 작업 장갑이나 공구 때문에 손가락 점이 자주 가려질 수 있어, 손목 하나로 위팔·아래팔 점수까지 잃지 않기 위해서다 |

## 활동 점수
- 1분 이상 정적 유지: 관리자 입력 (30초 촬영으로 판단할 수 없음)
- 작은 범위의 반복 동작 (분당 4회 초과): 위팔 각도의 극점 중 진폭 REPEAT_AMPLITUDE(기본 15도, 시작값) 이상인 것을 세어 분당 횟수로 환산
  - 좌우 위팔을 각각 세고 많은 쪽을 쓴다. 극점 2개(오르고 내림)를 1회로 센다.
  - 처음 움직이기 시작한 지점은 극점으로 세지 않고, 실제로 방향이 바뀐 지점만 센다.
  - 활동 점수는 세션 전체에 하나로 정해 모든 프레임에 더한다.
- 크고 빠른 자세 변화 또는 불안정한 자세: 관리자 입력

## 프레임 점수
- 프레임마다 그룹 A(몸통, 목, 다리)와 그룹 B(위팔, 아래팔, 손목)의 필요한 점이 모두 유효할 때만 점수를 낸다.
  - 그룹 A: 어깨(11, 12)와 골반(23, 24), 귀 한쪽 이상, 다리(골반·무릎·발목) 한쪽 이상
  - 그룹 B: 좌우 중 한쪽 이상에서 어깨·팔꿈치·손목이 모두 유효. 검지·새끼 점이 무효이면 그쪽 손목은 판정하지 않음(1점)
- 그룹 B는 좌우를 각각 계산하고 높은 쪽을 쓴다. 한쪽만 유효하면 그쪽을 쓴다.
- 무릎 굽힘 보정은 유효한 쪽 중 큰 각도를 쓴다.
- 앉은 작업이면 무릎 굽힘 보정을 적용하지 않는다.
- 최종 점수는 REBA 표 A·B·C와 하중, 손잡이, 활동 점수로 계산한다 (1~15점).

## 세션 결과 (assessments에 저장)
| 값 | 정의 |
|---|---|
| valid_frame_ratio | 점수를 낸 프레임 / 전체 분석 프레임 |
| high_risk_ratio | 유효 프레임 중 최종 점수 8점 이상 비율 |
| score_p90 | 유효 프레임 최종 점수의 90번째 백분위 (nearest-rank 방식, 항상 정수 점수) |
| level | score_p90의 위험도 단계 |
| part_summary | 부위별 점수 분포. 유효 프레임에서 부위마다 점수별 프레임 수 (예: {"trunk": {"1": 12, "2": 30}, ...}). wrist_unjudged_ratio(그룹 B에 쓴 쪽의 손목을 판정하지 못한 유효 프레임 비율)도 함께 둔다 |

- valid_frame_ratio가 MIN_VALID_RATIO(기본 0.5, 시작값) 미만이면 결과를 저장하지 않고 재촬영을 안내한다.
- 서버는 받은 관절 좌표로 같은 코드(web/src/core/)를 실행해 다시 계산하고, 그 결과만 저장한다.

## 위험도 단계
| 들림 단계 | REBA 최종 점수 | REBA 조치 수준 |
|---|---|---|
| 낮음 | 1~3 | 무시 가능, 낮음 |
| 주의 | 4~7 | 중간 |
| 높음 | 8~10 | 높음 |
| 매우 높음 | 11~15 | 매우 높음 |

- REBA 조치 수준의 점수 구간은 구현 전에 원 논문으로 재확인한다.

## 2D 보정
- 기본값은 REBA 표준 각도 구간을 그대로 쓴다.
- 부위별 각도 보정값(ANGLE_OFFSET)은 설정값으로만 두고 기본값은 0이다.
- AI Hub 라벨 분석에서 라벨러의 20도 경계가 2D 기준 약 25~30도에서 나타났다 (docs/aihub-label-codes.md). 이 결과를 보정값으로 쓰는 것은 AI Hub 이용정책 문의 답변을 받은 뒤 정한다.

## 검증
- AI Hub 데이터와는 대응되는 경계만 비교한다: 몸통 숙임 여부, 위팔 20도와 90도 경계, 목의 큰 숙임 여부.
- 검증에는 스무딩을 적용하지 않는다 (정지 이미지이므로).
- 검증 결과는 집계 수치만 남긴다.
