# UX 개선 목록

|---|---|---|---|
| 시연 QR 창의 단위작업 선택 (개선안 상세 → 시연 촬영) | 선택됨과 초점이 구분되지 않고, 글자 입력칸처럼 보인다 | SegmentedControl (web/src/components/choice-field.tsx) | 동그라미 표시 변형 검토. 동작은 이미 기본 라디오(fieldset, legend, 방향키)라 모양만 다룬다 |
