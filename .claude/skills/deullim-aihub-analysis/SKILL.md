# 들림 분석 도구와 원본 데이터

## 읽을 문서
- docs/aihub-label-codes.md: 출처와 이용 표시, 확인된 데이터 구조, 코드 역추정 결과, 미해결 질문
- CLAUDE.local.md: 데이터셋별 위치와 사용 제한

## 규칙 (AI Hub 이용정책의 국외 반출, 제3자 열람 금지 조항 때문)
- 원본은 압축을 풀지 않고 zipfile로 직접 읽는다. data/ 안에 파일을 만들거나 고치지 않는다.
- Claude Code는 원본 zip이나 JSON을 직접 열어 보지 않는다.
- 터미널 출력과 결과 파일에는 건수, 비율, 분위수 같은 집계만 넣는다. 개별 레코드, 좌표, 파일명은 출력하지 않는다.
- 통계값은 표본이 10건 미만이면 "-"로, 건수표의 1~9는 "<10"으로 가린다.
- AI Hub 데이터는 Kaggle 등 외부 서비스로 보내지 않고 로컬에서만 처리한다.
- 결과 파일은 analysis/**/results/에 버전을 붙여 새로 저장하고 커밋하지 않는다.
- 새 Python 의존성이 필요하면 멈추고 묻는다.

## 절차
1. 입력 파일 경로와 읽는 방식, 출력할 집계 항목을 먼저 제안하고 승인받는다.
2. 큰 입력은 레코드 수를 줄인 축소판(--limit)으로 출력과 저장을 먼저 확인하고, 소요 시간과 메모리를 보고한다.
3. 각도 계산 같은 순수 함수는 분리해 합성 좌표로 단위 테스트한다. 실제 데이터를 테스트에 쓰지 않는다.
4. 보고에는 집계 결과만 붙이고, 코드 값의 의미 해석은 사용자가 한다.

## 점검표
- [ ] 출력과 결과 파일에 개별 레코드, 좌표, 파일명이 없다.
- [ ] 작은 그룹을 가렸다.
- [ ] 결과 파일이 git status에 나타나지 않는다 (.gitignore의 analysis/**/results/).
